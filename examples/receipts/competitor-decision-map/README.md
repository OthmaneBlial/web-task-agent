# Competitor Decision Map

This is a deterministic, bundled demo package. It proves the package shape and source-trace reading flow without using an API key, browser session, or live network request. It is not a claim that a fresh live run produced these findings.

Scenario: Decide how to position a research product alongside browser automation, web extraction, and durable agent frameworks without claiming unverified superiority.

Start with [receipt.html](receipt.html) for the visual decision handoff, then read [handoff/workflow-brief.md](handoff/workflow-brief.md), [report.md](report.md), and [evidence/sources.json](evidence/sources.json).
