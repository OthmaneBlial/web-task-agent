# Support

## Where to ask

- Use **GitHub Discussions** for workflow ideas, research patterns, setup questions, and showing a useful research receipt.
- Use **GitHub Issues** for reproducible bugs and concrete feature proposals.
- Use the private security advisory flow described in [SECURITY.md](SECURITY.md) for vulnerabilities.

## Before opening an issue

1. Run `web-task-agent storage gate` and include the non-sensitive result.
2. Include the command, operating system, Node version, selected browser backend, and a redacted error message.
3. Do not paste API keys, cookies, private reports, database files, or URLs that require authentication.

## Scope

The project is maintained in the open and is local-first by default. Best-effort community support is provided for documented flows; hosted operations, site-specific bypasses, and unsafe automation are out of scope.
